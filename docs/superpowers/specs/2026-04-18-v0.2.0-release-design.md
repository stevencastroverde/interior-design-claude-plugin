# Design Spec — v0.2.0 Release

**Date:** 2026-04-18
**Branch:** `sc/v0.2.0-release`
**PR target:** `main`

## Overview

This release upgrades the `schedule-creator` skill from a single-sheet to a three-sheet Excel workbook and adds two new skills — `moodboard-pdf` and `autocad-hatch-pat` — that have been battle-tested in the Cowork environment. The plugin version bumps from `0.1.0` to `0.2.0`.

## File Changes

### Commit 1 — schedule-creator upgrade

Overwrite both files entirely with content from `PLUGIN_UPDATE_PLAN.md`:

- `plugins/interior-design/skills/schedule-creator/SKILL.md`
- `plugins/interior-design/skills/schedule-creator/scripts/build_schedule.py`

**What changes:** Single-sheet → three-sheet workbook:
- **Sheet 1 — `[Project] Schedule`**: All rooms on one sheet, separated by blue section headers. Finish/material items (PT, BB, HW, FT, WT, WC, ST, MT) excluded.
- **Sheet 2 — `Materials & Finishes`**: All finish items from all rooms, organized by type. CT-x codes auto-renamed to ST-x.
- **Sheet 3 — `Room Finish Schedule`**: Plain CAD/Revit-compatible table (no fill colors). Columns: ROOM NO., ROOM NAME, FLOOR, BASE, NORTH, EAST, SOUTH, WEST, HEIGHT, CEILING MATERIAL / FINISH, NOTES. Rooms auto-numbered from 101. Interactive workflow: Claude prompts user to assign finish codes to each surface before building.

JSON format updated to support multi-room (`rooms` array) while remaining backwards-compatible with legacy single-room (`categories`) format.
